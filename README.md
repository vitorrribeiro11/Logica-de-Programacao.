# Lógica-de-Programação.
Meu aprendizado de Logística de Programação.

O que eu aprendi sobre o que é um Algoritmo:
Um Algoritmo é um valor/valores de entrada que gera  um valor/valores na saída.
Exemplo: 1+1=Valor de entrada e 2=Valor de Saída.
Algoritmo também é uma ferramenta para corrigir problemas de programação específicos.

O Algoritmo é composto por 3 fases Entrada, Processamento e Saída de Dados.

Os Programas do Computador é um Algoritmo escrito em Linguagem de Programação como C, C++, C#, Java, Python e etc;Que são Executados pelo Computador.

O computador é uma ferramenta utilizada para solucionar problemas que envolvem a manipulação de informações.
